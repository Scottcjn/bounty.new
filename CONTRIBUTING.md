# Contributing to bounty.new

Thank you for your interest in contributing!

## Quick Start

1. Fork this repo
2. Clone: `git clone https://github.com/YOUR_USERNAME/bounty.new.git`
3. Create branch: `git checkout -b feature-name`

## Setup

```bash
npm install
npm run dev
```

## Code Standards

- Use consistent formatting
- Add comments for complex logic
- Test your changes

## Submitting

1. Commit with descriptive messages
2. Push to your fork
3. Open a Pull Request

## Bounty Program

Earn RTC tokens! See: https://github.com/Scottcjn/rustchain-bounties
